Cadastro e listagem de contatos com custom post type e shortcode.

== Description ==

Cria o tipo de conteúdo Contato com telefone, e-mail, WhatsApp e empresa.
Lista os contatos em qualquer página com o shortcode [cc_contatos].

== Installation ==

1. Envie a pasta para wp-content/plugins
2. Ative em Plugins
3. Cadastre contatos no menu Contatos
4. Use [cc_contatos] numa página
